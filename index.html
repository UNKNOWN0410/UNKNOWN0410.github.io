IRIS – Threat Intelligence Aggregator

When a SOC analyst looks into a suspicious IP, domain, hash or email, they have to check four or five threat-intel sites by hand. IRIS does all of that in a single API call. Built by a team of six in 36 hours.

  • Queries VirusTotal, AbuseIPDB, Shodan and IPInfo in parallel and normalizes the results
  • Risk score plus a Malicious / Suspicious / Clean verdict, with MITRE ATT&CK technique mapping
  • City-level geolocation, full query audit trail, and keeps working if one feed goes down
Node.jsTypeScriptExpressPostgreSQLRedisDockerMITRE ATT&CK

OSINT Recon Framework

A modular CLI for passive reconnaissance and attack-surface discovery that never touches the target directly.

  • Subdomains from certificate-transparency logs (crt.sh)
  • Wayback Machine URL harvesting and Google dorks for exposed configs, backups and admin panels
  • Risk scoring from low to critical, SQLite storage and Markdown reports

Pi Sentinel

A lightweight home-network security monitor with no dependencies beyond the Python standard library.

  • Detects SSH brute-force attempts and blocks the source IPs with iptables
  • Flags connection floods and new listening services, with Telegram alerts

PortScout & Home Network Audit

A multithreaded TCP port scanner written from scratch to learn how Nmap works under the hood.

  • Ping sweep, connect scan with 200 threads, and banner grabbing
  • Flags risky services and exports JSON/CSV reports
  • Used it to audit my home network. It found Telnet and FTP open on the router, and MySQL and VNC exposed on a laptop
